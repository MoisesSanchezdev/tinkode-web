# Capturas de proyectos

Esta carpeta queda preparada para capturas futuras de proyectos autorizados.

## Reglas

- Agregar solo imágenes aprobadas para publicación.
- No incluir datos personales, credenciales, repositorios, URLs privadas ni información interna.
- Optimizar las imágenes antes de publicarlas.
- Usar nombres descriptivos en kebab-case.
- Escribir texto alternativo específico cuando se integren en la página.

## Nombres sugeridos

- `lpt-home.webp`
- `robot-explota-globos-admin.webp`
- `robot-explota-globos-public.webp`
- `nfc-experience-concept.webp`

## Formatos y dimensiones

- Preferir `.webp` para capturas finales.
- Usar `.png` solo si se necesita máxima nitidez de interfaz.
- Ancho recomendado: entre 1200 px y 1600 px.
- Evitar imágenes pesadas sin compresión.
