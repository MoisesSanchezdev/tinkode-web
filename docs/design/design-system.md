# Dirección visual inicial

Esta documentación describe solo la dirección visual inicial. El sistema de diseño completo se desarrollará en una fase posterior.

## Base visual

- Negro como base principal.
- Verde neón como acento tecnológico.
- Azul eléctrico como acento secundario.
- Blanco para contraste y legibilidad.
- Mucho espacio negativo.
- Minimalismo tecnológico.
- Grid sutil.
- Detalles HUD discretos.
- Apariencia premium.
- Apariencia moderna.
- Orientación comercial.
- Excelente experiencia móvil.

## Restricciones

- No saturar visualmente la interfaz.
- No abusar del neón.
- No crear apariencia de videojuego.
- No crear estética de hacker clandestino.
- No usar plantillas genéricas.
- No añadir animaciones innecesarias.
- No definir todavía todo el sistema de diseño.
